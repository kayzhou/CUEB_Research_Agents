## 执行流程

### 步骤 0：证据链统筹（卡点，先于动笔）

> 实证工作是证据驱动的——证据链就是论文的逻辑链。每出新证据，动笔前先重组证据链。

1. **清点证据**：列出所有可用实证输出（表/图），逐条一句话标注它证明了什么。
2. **构建证据链**：按逻辑排列回答——我们想知道什么 → 我们怎么知道 → 我们发现什么 → 有没有替代解释 → 为什么是这个机制。
3. **映射到章节**：节数不固定（5-8 节不等），可合并/拆分/重排。基准与稳健紧密则合并；机制多渠道则拆分；子样本本身是核心故事则独立成节。
4. **更新引言路线图**：引言「Section X does Y」段必须与正文实际组织一致。
5. **更新 section-brief**：每个重组后章节更新目标/状态。
6. 写入 `evidence-chain.md`。**人批准后动笔。**

### 步骤 1：写前装载

- 读对应 section-brief，确认这一轮只解决什么、不解决什么。
- 从 `paper-lib/` 检索并锁定 2-3 篇主题/方法最接近的范文（`paperlib_index.py --search <关键词>`），读 PDF 原文。
- 读范文解剖笔记的模块 B（逐段解剖）、C（句式库）、D（段落微观结构）。无解剖笔记先补写再动笔。
- 对照 checklist 与结果文件，锁定本章必须引用的表图与关键数字。
- 从句式库提取本章脚手架（开篇句式、结果报告句式、贡献声明句式）。

### 步骤 2：判断任务类型并执行

- **章节起草**：先更新 section-brief → 先产出 `sections_cn/` 中文讨论稿 → 再同步 `sections/` 英文投稿稿（结构与事实口径一致）。
- **中转英**：重写为符合 finance/econ 英文习惯的段落，保留全部事实/数字/限定条件，不擅补新结论。
- **中转中**：把口语碎片重组为学术段落，允许保留必要 `[TODO]`/`[CHECK]`。
- **英文精修/去 AI 味**：只修逻辑跳跃、术语漂移、机械连接词、空泛夸饰、中式英语。原文已合格则明确「保持原文」。
- **逻辑核对（写作层 E 类）**：只报实质问题（逻辑断层、术语混乱、表图与正文不一致、结论超证据）。跨节矛盾/识别链断裂（P1/P2）标记后移交 M5 的 7R。
- **表图 note/caption**：标题直接命名内容；note 自明（样本、变量、估计方法、参数含义、SE/聚类或置信区间、显著性规则、平滑/缩尾/标准化处理）。中英双版只切换语言不删信息。

### 步骤 3：写作执行原则

1. 高阈值改写：原文已清楚准确就保留，只修实质问题。
2. 先抓逻辑主线，再改句子；不为表面顺滑打散因果链。
3. 除非天然并列，保持连贯段落，不把连续论证改成机械列表。
4. 英文稿保持 LaTeX 纯净；中文稿保持普通正文，不堆 Markdown 装饰。
5. 去 AI 味的核心是去空话、机械过渡、破折号滥用、三点式堆砌、无意义对称句——不是换高级词。
6. 段落论证遵循四拍结构（判断 → 数字 → 经济显著 → 对比），与范文模块 D 一致。
7. 句式复用而非抄袭：用句式骨架填入本论文具体事实。

### 步骤 4：贡献审计闭环（先读后写）

- 文献综述的子节划分与共性局限论证必须与贡献审计比对矩阵和文献簇分组一致。
- 与文献对话时**引用直接相关的结果**：引用 paper-lib 命中论文的具体结论与系数量级，引用前回 PDF 原文核对（规则见 `paper-lib/README.md` §三）。
- 引言贡献段每条贡献可溯源到比对矩阵的具体文献行。
- 贡献审计评级「中/低」的维度，引言不得用强声称。
- 贡献审计未完成，不得开始文献综述与引言写作。

### 步骤 5：输出前自检

术语一致性 / 信息完整性（数字、样本期、变量定义、限定条件未误删）/ 表图对应 / 语言纯净度（英文无残留中文与全角标点；中文无翻译腔）/ 修改必要性（别为「显得有动作」而改合格句）/ 范文对齐度 / 正文数字来自结果文件 / `[TODO][CHECK][SPEC]` 投稿前清零。

## Common Pitfalls

1. 把「润色」做成大幅改写导致原意走样。
2. 把连续论证拆成机械列表。
3. 为去 AI 味堆更华丽的词。
4. 中英版本不同步导致两套口径。
5. 表图 note 只写聚类说明，漏样本/变量/估计口径。
6. 触及数据/方法的改动在写作模块越界处理（应回 M2/M3）。

## 独立运行说明

M4 可独立运行：提供结果表图 + 哪些进正文 + 目标期刊风格即可起草。
若无 M1 贡献审计，则引言贡献段先标 `[CHECK]`，待补审计后再定强度。
纯写作/润色/翻译任务可只跑步骤 1-3，不必每次重做证据链。

模板见 `templates/`：`evidence-chain-template.md`、`section-brief-template.md`、`table-note-template.md`。
