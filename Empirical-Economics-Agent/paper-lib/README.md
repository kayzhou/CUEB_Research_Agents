# paper-lib — 期刊范文知识库

> 存放目标期刊的已发表论文 PDF，是本框架的**写作风格基准 + 文献证据来源**。
> 当前收录：《管理世界》2022–2026 年各期全文（664 篇，见 `index.csv`）。
> 本目录**只读**：不修改、不删除、不在此写入任何产出文件（索引与风格 PDF 缓存除外）。

PDF 因体积和版权原因被 `.gitignore` 排除，Git 仓库只保存索引与说明。新环境必须从项目负责人提供的受控存储单独同步 PDF，并保持 `index.csv` 中的相对路径；本仓库不提供下载源。

## 一、目录与索引

```
paper-lib/
├── README.md                  # 本文件
├── index.csv                  # 全库索引（期刊/年份/期号/标题/路径），由脚本生成
├── style-references/pdfs/     # fetch_style_pdf.py 抓取的英文期刊范文缓存
└── 管理世界/
    └── 管理世界20XX年/管理世界20XX年X期/*.pdf
```

索引维护与检索（激活环境后运行）：

```bash
python code/utils/check_paperlib.py                    # 先验证索引中的 PDF 均存在
python code/utils/paperlib_index.py --build            # PDF 有增删后重建索引
python code/utils/paperlib_index.py --search 双重差分   # 标题关键词检索（AND）
python code/utils/paperlib_index.py --search 数字化 --year 2024
```

`check_paperlib.py` 返回非零状态时，M1/M4/M5 中要求“回 PDF 原文核对”的步骤必须标记为阻塞，不能只凭索引标题或模型记忆引用结论。

## 二、在各模块中的用法

### M1 选题立项：文献调研与贡献审计

1. 文献搜索顺序中，**paper-lib 是第一站**：`--search` 检索研究问题关键词，确认《管理世界》近五年是否已有直接相关研究。
2. 命中的直接相关论文进入贡献审计的比对矩阵（Tier 1/2 阅读对象优先从这里取），逐维比对识别策略、样本、结论。
3. 「严苛五问」中的"这个想法已经被做过了吗？""只是换了样本期吗？"必须以 paper-lib 检索结果为证据回答。

### M3 模型与实证：方法基准

1. 检索同方法论文（如 `--search 双重差分`、`--search 工具变量`），核对基准规格、固定效应选择、聚类层级、稳健性检验套路是否符合该刊惯例。
2. 方法类论文（如 DID 估计量可信性讨论）作为诊断检验的依据，写进脚本头部的"方法来源"注释。

### M4 论文撰写：写作风格与规范基准（核心用途）

1. **先解剖后动笔**：从 paper-lib 选 2–3 篇与本文主题/方法最接近的范文，按 M4 的范文解剖流程做解剖笔记（逐段解剖、句式库、段落微观结构），再起草。
2. **写作规范对齐**《管理世界》实证论文惯例：
   - 标题多用"X 如何影响 Y？——基于 Z 的证据"结构；
   - 引言先讲制度背景与政策重要性，再讲文献缺口与边际贡献（通常三条）；
   - 表格规范：变量中文名 + 括号内标准误 + 三星显著性；表注自明；
   - 机制分析独立成节，异质性按产权/规模/地区等维度展开。
3. **引用直接相关的结果**：正文与文献综述引用 paper-lib 中直接相关论文的**具体结论与系数量级**（如"与 XX（2024）发现的 X% 效应相比"），不做泛泛引用；引用前用索引定位原文并核对原始数字。

### M5 审稿与返修：质量比对基准

1. 7Q 质量评估中"结论方向是否与文献一致、贡献是否超越文献"以 paper-lib 中同主题论文为比对对象。
2. 模拟专家评审的审稿人 persona 参照该刊已发表论文的水准设定攻击强度。

## 三、引用规则（不可违反）

1. 引用必须**直接相关**：只引用与本文研究问题、识别策略或机制直接对话的论文，不为凑引用数量而引用。
2. 引用的结论、系数、样本区间必须**回到 PDF 原文核对**，不凭标题或记忆转述。
3. 风格参考是"句式骨架复用"，**不是抄袭**：借鉴段落推进结构与句式模板，全部事实内容替换为本文内容。
4. 新增期刊（如其他中文顶刊或英文期刊）按 `期刊名/期刊名年份/` 的目录惯例放入，并重建索引。
