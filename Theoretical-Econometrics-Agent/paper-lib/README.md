# paper-lib — 用户提供的领域资料入口

发行包不内置特定研究主题的论文、DOCX 或二次整理稿。本目录仅说明外部资料的管理边界；
实际文献应放入具体项目的 `projects/{slug}/literature/library/`。

## 使用规则

1. 仅保存来源和使用权限明确的材料，不得把受限文件直接纳入公开发行包。
2. PDF 应配套可检索的同名文本；DOCX 如需检索，应另行导出纯文本或 Markdown。
3. 引用结论前必须回到原文核对，并在文献矩阵登记核验状态。
4. 无法核验的内容标记为 `cannot verify`，不得作为定理、贡献或事实依据。
5. 用户提供的领域资料与框架自带的通用案例相互独立；通用案例见
   `examples/generic-qml-workflow/`。
