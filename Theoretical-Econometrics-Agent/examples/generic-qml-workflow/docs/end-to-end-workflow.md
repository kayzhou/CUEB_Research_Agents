# 通用理论计量案例：线性模型的高斯 QML

> **案例状态**：仅作 M1–M7 的文档与流程示例。未执行数值模拟，未编译论文，
> 未对文献新颖性作结论，也未将任何候选证明标记为已核验。

## 1. 研究任务与边界

考虑独立同分布样本 \(\{(y_i,x_i)\}_{i=1}^n\)，其中 \(y_i\) 为标量，
\(x_i\in\mathbb{R}^k\) 可包含常数项：

\[
y_i=x_i'\beta_0+u_i,\qquad E(u_i\mid x_i)=0.
\]

本案例的任务是：

1. 用高斯准极大似然估计 \(\beta_0\)；
2. 在允许条件异方差时构造稳健标准误；
3. 为一致性与渐近正态性建立可审查的证明蓝图；
4. 设计但不伪造 Monte Carlo 结果；
5. 展示从模型设定到终稿审查的完整交付链。

该模型是教学用基准，不构成研究贡献。实际项目必须换成用户的研究问题，并重新完成
识别、文献、新颖性、证明和模拟审查。

## 2. M1 — 模型设定

### 2.1 记号与参数空间

- 参数：\(\beta_0\in\mathcal{B}\subset\mathbb{R}^k\)，其中
  \(\mathcal{B}\) 为紧集，且 \(\beta_0\) 位于其内点。
- 条件均值：\(E(y_i\mid x_i)=x_i'\beta_0\)。
- 条件方差：\(E(u_i^2\mid x_i)=\sigma_i^2\)，允许随 \(x_i\) 变化。
- 工作方差参数：\(\sigma^2\in[\underline{\sigma}^2,\overline{\sigma}^2]\)，
  仅用于构造高斯准似然。

高斯准对数似然为

\[
\ell_n(\beta,\sigma^2)
=-\frac n2\log(2\pi\sigma^2)
-\frac{1}{2\sigma^2}\sum_{i=1}^n(y_i-x_i'\beta)^2.
\]

即使 \(u_i\mid x_i\) 不服从正态分布，最小化残差平方和仍给出
\(\beta\) 的准极大似然估计量。分布错设会影响方差公式，因此不得默认使用同方差标准误。

### 2.2 识别

若

\[
Q:=E(x_ix_i')
\]

正定，则总体平方损失
\(E[(y_i-x_i'\beta)^2]\) 在 \(\beta_0\) 处唯一最小，
从而 \(\beta_0\) 被条件均值限制识别。

### 2.3 Gate 1

进入后续模块前，研究者必须确认：

1. \(x_i\) 是否包含常数项；
2. 条件均值限制是否适合实际数据；
3. 样本是否可按独立同分布处理；若不可，后续 LLN、CLT 与协方差估计必须改写；
4. 是否允许条件异方差；
5. 参数空间与矩条件是否足以支持所需结论。

## 4. M3 — QML 估计

给定 \(\sigma^2>0\)，最大化 \(\ell_n\) 等价于最小化残差平方和。
以下闭式解对应无约束问题；若估计时显式施加 \(\beta\in\mathcal B\)，
则应在 \(\mathcal B\) 上求约束最小二乘。若无约束解位于 \(\mathcal B\) 内且
\(X'X\) 非奇异，则

\[
\widehat\beta=(X'X)^{-1}X'y,
\qquad
\widehat u_i=y_i-x_i'\widehat\beta.
\]

当结果位于预先规定的方差参数区间内时，工作方差的准极大似然估计量为

\[
\widehat\sigma^2=\frac1n\sum_{i=1}^n\widehat u_i^2.
\]

若该值落在参数区间外，约束估计量位于相应边界。这一定义不同于带自由度修正的
有限样本无偏方差估计量；正式报告必须说明采用哪一种。

允许条件异方差时，以下以 HC0 型三明治估计为例，定义

\[
\widehat Q=\frac1n\sum_{i=1}^n x_ix_i',
\qquad
\widehat\Omega=\frac1n\sum_{i=1}^n x_ix_i'\widehat u_i^2.
\]

\(\widehat\beta\) 的渐近协方差估计为

\[
\widehat{\operatorname{Avar}}(\widehat\beta)
=\frac1n\widehat Q^{-1}\widehat\Omega\widehat Q^{-1}.
\]

若数据存在聚类、序列相关或空间相关，上式不再充分，必须改用与依赖结构一致的协方差估计量。

### 4.1 算法记录

1. 检查 \(X\) 的维度、缺失值与数值秩；
2. 用 QR 或 SVD 求解最小二乘问题，避免显式计算 \((X'X)^{-1}\)；
3. 保存估计值、残差、条件数和收敛状态；
4. 同时报告稳健标准误的具体版本；
5. 将所有人工选择写入项目元数据。

### Gate 3

研究者须批准外生性条件、协方差估计方法和数值秩处理规则。矩阵近奇异时不得静默继续。

## 5. M4 — 渐近理论

以下条件仅用于展示证明结构：

- **A1（抽样）**：\(\{(y_i,x_i)\}_{i=1}^n\) 独立同分布。
- **A2（条件均值）**：\(E(u_i\mid x_i)=0\)。
- **A3（矩条件）**：\(E\|x_i\|^4<\infty\) 且 \(E(u_i^4)<\infty\)。
- **A4（识别）**：\(Q=E(x_ix_i')\) 正定。
- **A5（参数空间）**：\(\mathcal{B}\) 紧，\(\beta_0\) 为内点。

### 5.1 候选结论

在 A1–A5 下，

\[
\widehat\beta\xrightarrow{p}\beta_0,
\]

并且令 \(\Omega=E(x_ix_i'u_i^2)\)，则

\[
\sqrt n(\widehat\beta-\beta_0)
\xrightarrow{d}
\mathcal N(0,Q^{-1}\Omega Q^{-1}).
\]

### 5.2 证明蓝图

一致性证明应逐步核对：

1. 样本平方损失对总体平方损失的一致收敛；
2. 总体目标在 \(\beta_0\) 处的唯一最小性；
3. 参数空间与目标函数满足 argmin 定理条件。

渐近正态性证明应逐步核对：

1. 写出
   \[
   \sqrt n(\widehat\beta-\beta_0)
   =\left(\frac1nX'X\right)^{-1}
     \frac1{\sqrt n}\sum_{i=1}^n x_iu_i;
   \]
2. 用 LLN 证明 \(n^{-1}X'X\to_p Q\)；
3. 用多元 CLT 证明
   \(n^{-1/2}\sum_i x_iu_i\to_d\mathcal N(0,\Omega)\)；
4. 用 Slutsky 定理合并结论；
5. 单独证明 \(\widehat\Omega\to_p\Omega\) 后，才能使用三明治标准误。

### 5.3 状态边界

这些结论是规范化示例，不等于具体研究中的“已证定理”。只要抽样结构、矩条件或估计量发生改变，
证明就必须重新建立。未经研究者逐条核验，状态只能标记为 `candidate` 或 `draft`。

## 6. M5 — Monte Carlo 设计

### 6.1 示例 DGP

可采用

\[
x_{i1}=1,\qquad x_{i2}\sim\mathcal N(0,1),\qquad
u_i=(1+0.5|x_{i2}|)\varepsilon_i,
\qquad \varepsilon_i\sim\mathcal N(0,1),
\]

其中 \(\varepsilon_i\) 与 \(x_{i2}\) 独立，并令 \(\beta_0=(1,0.5)'\)。
该设计故意引入条件异方差，用于比较同方差标准误与三明治标准误。

建议将样本量、重复次数和随机种子写入 `simulation_design.yaml`。调试阶段可用少量重复，
正式重复次数必须在 Gate 5 前由研究者批准，不在文档中预设为已经执行。

### 6.2 必须保存的原始字段

- replication 编号与随机种子；
- \(n\)、参数真值、\(\widehat\beta\)；
- 同方差与稳健标准误；
- 置信区间覆盖指示；
- 数值秩、失败标记和错误信息。

汇总脚本应从原始记录生成 bias、RMSE、经验标准差、平均估计标准误、覆盖率和失败率。
不得手工填写结果表，也不得删除失败重复。

### 6.3 验证顺序

1. smoke：小样本、少量重复，只检查维度、种子和输出；
2. 特例：令异方差系数为 0，与标准同方差线性模型对照；
3. 交叉实现：用第二种语言或独立函数比对同一固定样本上的估计值；
4. final：仅在设计获批且前三步通过后执行。

### Gate 5

本仓库未随案例提供运行结果，因此不存在可供引用的数值结论。正式项目必须报告实际引擎、
版本、种子、失败率和结果文件位置。

## 7. M6 — 论文写作

本案例若用于教学性报告，可按以下顺序组稿：

1. 引言：说明示例目的，不声称方法创新；
2. 模型与识别：给出条件均值、参数空间和 \(Q\) 正定条件；
3. 估计方法：区分工作高斯似然与真实条件分布；
4. 渐近理论：逐条引用 A1–A5，并保留证明状态；
5. Monte Carlo：只引用脚本生成的表；未运行时明确标注 `not run`；
6. 结论：只总结已经建立或实际执行的内容。

LaTeX 正文中的符号、假设编号、定理陈述和附录证明必须与
`proofs/notation_registry.md`、`proofs/assumptions.md` 和 `proofs/theorem_map.md`
保持一致。编译产物不属于发行内容。

### Gate 6

没有文献核验、证明核验和实际模拟结果时，该材料只能作为工作流示例，不得包装为可投稿论文。

## 8. M7 — 审稿与返修

对该案例进行终稿审查时，至少应提出以下问题：

1. 条件均值限制是否足以识别 \(\beta_0\)；
2. A3 是否足以支持所调用的 LLN、CLT 与稳健方差一致性；
3. 数据若并非独立同分布，哪些结论需要重写；
4. 标准误是否与允许的异方差结构一致；
5. 模拟表是否由保存的原始结果生成；
6. 文献和贡献措辞是否超出已核验材料；
7. 候选定理是否被错误写成已完成结论。

返修记录必须对每项意见给出处理动作、修改位置和状态。未解决的重大问题不得标记为完成。
