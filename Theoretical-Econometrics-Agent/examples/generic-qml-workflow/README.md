# 通用案例：线性模型的高斯 QML 工作流

本案例用最小线性模型说明 M1–M7 的衔接方式，重点是研究契约、人工闸门和学术诚信边界，
不绑定空间面板、结构断点或其他特定研究主题。

## 案例模型

\[
y_i=x_i'\beta_0+u_i,\qquad i=1,\ldots,n,
\]

其中 \(E(u_i\mid x_i)=0\)。高斯分布仅作为准似然的工作假设；允许条件异方差，
因此推断采用三明治协方差矩阵。

## 内容

- [`docs/end-to-end-workflow.md`](docs/end-to-end-workflow.md)：M1–M7 的端到端文档示例。

## 使用边界

1. 本案例是文档示例，不是可直接投稿的论文或特定领域的参考答案。
2. 仓库未随本案例提供模拟结果、编译后的论文或已核验文献结论。
3. 文中的定理只展示规范陈述与证明蓝图；用于正式研究前仍须由研究者逐条核验。
4. 数值实现可从 `templates/paper-project/` 初始化到 `projects/{slug}/`，但该模板默认是
   空间面板断点骨架；用于本案例时必须替换全部不适用的模型、断点、DGP 与论文占位内容。
5. 新研究不得直接在 `examples/` 中继续开发。
