# examples — 通用文档案例（只读）

本目录只保留一个中性案例，用于说明 M1–M7 的交付关系、人工闸门与学术诚信边界。
新研究一律在 `projects/{slug}/` 中开展，不得直接修改示例。

## `generic-qml-workflow`

该案例以线性模型的高斯准极大似然为最小示例，不绑定空间面板、结构断点或其他特定主题。

- `README.md`：案例目的、模型与使用边界；
- `docs/end-to-end-workflow.md`：M1–M7 的端到端文档示例。

案例不包含模拟结果、编译后的论文、已核验文献结论或可直接投稿的研究成果。
需要可执行项目时，应使用 `scripts/init_project.py` 从 `templates/paper-project/` 初始化工作区，
再按实际模型改写配置、证明、代码和论文。当前模板默认是空间面板断点骨架；
用于其他模型时不得保留不适用的 \(W_N\)、断点或 regime 占位内容。
