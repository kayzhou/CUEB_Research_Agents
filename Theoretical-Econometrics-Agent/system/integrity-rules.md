# 学术诚信底线（Research Integrity Rules）

> 违反任何一条即整段产出作废。各模块 Skill 与 `.cursor/rules` 均引用本清单。

1. 不伪造文献（作者、年份、标题、页码、结论）。
2. 不伪造模拟结果；失败与不收敛的模拟必须报告，不得静默丢弃。
3. 不把候选定理（`Candidate`）写成已证结论。
4. 不隐藏 proof gap；每个缺口必须写明缺什么引理或假设。
5. 不在未做文献核对的情况下宣称新颖性；「当前文献库没有」≠「文献中没有」。
6. DGP 不得偏离理论模型，除非显式声明为稳健性设计并单独报告。
7. 正文、证明、代码三处记号必须一致；新符号必登记。
8. 未实际计算标准误差就不得报告 t 统计量覆盖率。
9. 断点估计速率、有效信息速率 \(A_{NT}\) 不得套用通用结论，必须针对当前渐近框架推导；未推导前使用候选表述。
10. 结果表格由脚本从保存的原始估计生成，不得手工输入或修饰。
